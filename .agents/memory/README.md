# Project memory

Store one durable decision or lesson per dated Markdown file. Each entry should
state who decided it, why it matters and how future work should apply it. Link
every entry from this index.

Do not store credentials, raw sessions or personal data. A coding agent's private
memory is not a substitute for this shared project memory.

Before adding an entry, search for an existing decision and decide whether the
new fact belongs in memory, knowledge or a skill. Use a dated filename, add the
source, decision, reason and application rule, then update this index in the same
change. When an entry is obsolete, remove or supersede it only after checking
links and recording the replacement; do not leave stale copies that compete with
the current rule.
